# ESP32 智能语音办公闹钟功能定义文档

## 1. 文档定位

本文档用于说明当前代码主线中已经具备或已经接线完成的功能。

本文档不再保留早期“产品完全体”假设，而是以当前固件真实能力为准。

---

## 2. 当前平台约束

1. 软件平台为 `ESP-IDF on ESP32-S3`。
2. 当前时间基线依赖联网后的 `SNTP` 校时。
3. 设备断电后不假定存在持续保时能力。
4. 低干扰显示当前以 `LOW_CLOCK` 页面实现。
5. Todo 编辑不在设备端完成，当前由外部 Web 提供数据源。

---

## 3. 当前核心功能

### F01 上电启动与模块加载

系统上电后，按固定顺序初始化并启动各模块，包括：

- 显示
- 背光
- 按键
- 本地设置
- 环境采样
- 人体存在检测
- 音频
- 网络
- 提醒逻辑

若某模块初始化失败，系统会执行回滚停止，避免进入半初始化状态。

### F02 时间同步

设备联网并获得 IP 后，会通过 `SNTP` 获取标准时间。

当前行为：

- 联网后立即启动一次时间同步
- 后续按定时器周期再次同步
- 本地显示时间已按东八区修正

### F03 首页信息展示

首页当前可显示：

- 当前时间
- 日期
- 最近一个已启用闹钟
- 未完成 Todo 数量

当启用纯时钟布局时，首页只显示时间和日期。

### F04 环境采样与显示

当前环境采样包括：

- 温度
- 湿度
- 光照

来源分别为：

- `DHT11`
- `BH1750`

环境数据既用于显示，也用于后续提醒判断。

### F05 环境异常提醒

系统根据设置中的阈值判断环境异常。

当前支持的异常类型包括：

- 光照过低
- 光照过高
- 温度过低
- 温度过高
- 湿度过低
- 湿度过高

当异常发生时，可触发对应提示音，并带有冷却控制。

### F06 人体存在检测

系统通过 `LD2410C` 判断用户是否在设备附近。

当前实现融合：

- `UART` 数据
- `OUT` 引脚状态

该结果会影响：

- `LOW_CLOCK` 进入与退出
- 欢迎提示
- 休息提醒累计

### F07 低干扰时钟显示

当持续无人达到设定阈值后，系统会自动切换到 `LOW_CLOCK` 页面。

该页面仅保留：

- 时间
- 日期

当重新检测到人在位并达到退出阈值后，系统会返回首页。

### F08 欢迎提示

当系统从 `LOW_CLOCK` 恢复到正常状态时，会根据在位会话播放一次欢迎提示音。

同一轮会话中不会重复触发。

### F09 闹钟管理

当前系统支持本地闹钟管理，包括：

- 查看闹钟列表
- 新增闹钟
- 删除最后一个闹钟
- 修改闹钟时间
- 修改重复开关
- 修改语音开关
- 修改启用状态

闹钟配置会写入本地设置中。

### F10 闹钟提醒

当系统时间命中某个已启用闹钟时，会触发闹钟提示音。

当前实现中：

- 精度以分钟级匹配为主
- 非重复闹钟触发后会自动关闭

### F11 休息提醒

系统会根据连续在位时长触发休息提醒。

当前实现已将提醒逻辑接入，并使用本地在位会话累计。

当前代码中，这一功能按“连续在位达到 3 小时后触发一次，离开后重置”实现。

### F12 语音与提示音播放

系统使用 `I2S + MAX98357A` 播放嵌入式 `WAV` 音频资源。

当前已接入的音频类别包括：

- 欢迎提示
- 联网成功提示
- Todo 同步提示
- 环境异常提示
- 休息提醒
- 闹钟提醒

### F13 Todo 数据同步

Todo 数据当前由外部 Web 服务提供。

设备端负责：

- HTTP 拉取 Todo
- 本地缓存
- NVS 缓存持久化
- 手动同步
- Todo 完成状态切换
- Todo 删除

其中，设备端对 Todo 的完成 / 删除操作不是仅修改本地缓存，而是会立即请求 Web 端更新源数据；成功后再同步刷新本地快照。

### F14 Todo 展示

Todo 页面当前支持：

- 查看 Todo 列表
- 查看每条 Todo 的完成状态
- 进入设置页
- 对单条 Todo 执行完成 / 删除操作

### F15 Todo 设置

当前 Todo 设置支持：

- 手动同步
- 自动同步周期切换
- Todo 语音开关
- Todo 语音测试

### F16 环境设置

当前环境设置支持：

- 环境语音开关
- 环境语音测试
- 环境采样周期调整
- 温度、湿度、光照阈值调整
- 环境提醒总开关

### F17 首页显示设置

当前首页设置支持：

- 完整布局 / 纯时钟布局切换
- 12/24 小时制切换
- 整点提示开关

### F18 低干扰页设置

当前 `LOW_CLOCK` 设置支持：

- 12/24 小时制
- 进入阈值
- 退出阈值

---

## 4. 当前功能边界

1. 当前系统主界面已经不是旧文档中的 `SETTINGS / NETWORK / POWER` 结构。
2. Todo 编辑仍依赖外部 Web 页面，设备端不负责文本录入。
3. `DHT11` 当前仍然存在一定稳定性问题。
4. 当前 Todo/配置 JSON 解析已集中到 `sync_protocol`，后续仍可替换为更完整的 cJSON 组件实现。
5. 当前系统重点是功能主链打通，不以产品化完整度为目标。
6. 后续 Web 控制中心、配置快照、状态上报与事件上报扩展方案，见 `docs/plans/2026-06-09-web-device-control-center-design.md`。
