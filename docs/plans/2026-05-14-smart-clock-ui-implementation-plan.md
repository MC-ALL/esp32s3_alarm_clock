# 智能闹钟界面实现计划

## 1. 目标

基于已确认的设计，完成一套纯静态 `HTML / CSS / JavaScript` 原型，并补齐给 `LVGL`、硬件、网络与语音同学使用的接口交接文档。

## 2. 实现步骤

1. 建立原型目录结构
- `index.html`
- `assets/styles.css`
- `assets/app.js`
- `docs/api/smart-clock-ui-handoff.md`

2. 搭建统一界面骨架
- 竖屏 `240x320` 设备画布
- 统一色板、字体、边距、分隔线与底部按键栏
- 统一面板、列表项、状态块样式

3. 实现正常显示首页
- 大时间区
- 系统状态区
- 环境参数条
- 实时语音提示区
- 最近闹钟区
- todo 列表区
- 底部按键栏

4. 实现极简显示页
- 只显示时间
- 与人体检测 / 无人倒计时联动

5. 实现设置页
- 浏览态与编辑态
- 声音、采样、语音三组配置项
- 按键提示随模式切换

6. 实现闹钟页
- 列表态
- 编辑态
- 新增、修改、删除、启停的模拟动作

7. 实现网络页
- WiFi 状态面板
- 扫描与连接动作入口
- NTP 与 todo 同步状态面板

8. 实现关机确认页与关机态
- 二次确认
- 关机后再开机的原型行为

9. 增加统一状态模拟
- 内存态数据对象
- 每秒时间刷新
- 30 秒无人进入极简模式
- 检测到人后返回首页
- 网络、闹钟、设置项的动作模拟

10. 覆盖空数据与异常场景
- 无待办
- 无闹钟
- 时间未同步
- WiFi 断开
- 传感器异常
- 雷达异常

11. 输出接口交接文档
- 页面字段
- 状态读取契约
- 动作接口契约
- 按键映射
- 异常展示规则

## 3. 文件布局

- `index.html`
- `assets/styles.css`
- `assets/app.js`
- `docs/plans/2026-05-14-smart-clock-ui-design.md`
- `docs/plans/2026-05-14-smart-clock-ui-implementation-plan.md`

## 4. 验证清单

- 六个核心页面可见
- 首页可进入设置 / 闹钟 / 网络 / 关机确认
- 各页底部按键提示正确
- 时间每秒刷新
- 无人 `30s` 后进入极简模式
- 检测到人后回首页
- 网络、闹钟、设置操作有可见反馈
- 场景切换可展示标准 / 离线 / 空数据 / 故障状态
- 接口文档与页面字段保持一致
