# 智能闹钟界面设计文档

## 1. 范围

本文档定义智能闹钟显示界面与操作界面的 HTML 原型设计，用作后续 `LVGL` 实现与多模块联调的交接依据。

本轮范围：
- 正常显示首页
- 极简显示页
- 设置页
- 闹钟页
- 网络页
- 关机确认页
- 关机态说明
- 传感器、按键、人体检测、网络与语音模块的界面接口边界

本轮不做：
- `LVGL` 实现
- 真实硬件驱动
- 真实网络、NTP、云同步
- 语音引擎实现
- 测试代码，除非后续单独提出

## 2. 页面集合

1. 正常显示首页
2. 极简显示页
3. 设置页
4. 闹钟页
5. 网络页
6. 关机确认页
7. 关机态

## 3. 页面路由与状态切换

- 开机默认进入正常显示首页。
- 连续无人达到 `30s` 时，从正常显示态进入极简模式。
- 极简模式检测到人后，立即返回正常显示首页。
- 首页按键：
  - `K1 -> 设置页`
  - `K2 -> 闹钟页`
  - `K3 -> 网络页`
  - `K4 -> 关机确认页`
- 各操作页底部统一保留返回首页的语义。
- 关机操作必须经过确认页二次确认。

## 4. 视觉方向

- 屏幕方向：`240x320` 竖屏
- 背景：纯黑
- 主文字：白色
- 辅助文字与分隔：灰色
- 不做动画
- 时间为最强视觉元素
- 布局尽量保持 `LVGL` 易迁移性

## 5. 首页布局

### 5.1 顶部主信息区
高度约占屏幕 `28%`。

左侧：
- 大时间显示区
- 日期小字，格式 `YYYY-MM-DD`
- 星期可放在日期旁
- `时分` 为全页最大字号
- `秒` 略小，作为辅助信息显示在右下侧

右侧：
- 系统状态区
- `SOUND`：静音 / 外放
- `AUDIO`：语音播报开 / 关

### 5.2 环境参数条
位于顶部主信息区下方，单独一行。

展示字段：
- 温度
- 湿度
- 光照

推荐格式：
- `TEMP 26C | HUMI 58% | LUX 320`

### 5.3 实时语音提示区
位于环境参数条下方。

规则：
- 展示当前或最近一次语音提示文本
- 建议显示 `1-2` 行
- 过长内容截断，不做滚动动画

### 5.4 最近闹钟区
展示最近一个即将触发的闹钟。

字段：
- 时间
- 触发星期
- 重复 / 单次

### 5.5 Todo 区
使用首页剩余主要空间。

规则：
- 每条待办单独一行
- 首页展示 `4-5` 条
- 超出显示 `+N more`

### 5.6 底部按键栏
四等分布局：
- `K1 设置`
- `K2 闹钟`
- `K3 网络`
- `K4 关机`

## 6. 极简显示页

- 纯黑背景
- 白色文字
- 只显示当前时间
- 不展示环境参数、待办、闹钟、按键说明
- 检测到人后自动返回首页
- 返回首页可由雷达恢复检测到人或用户重新操作触发

## 7. 设置页

共用统一结构：
- 顶部标题栏
- 中部列表区
- 底部按键栏

分组：

### 7.1 声音设置
- `sound`：静音 / 外放
- `audio`：语音播报开 / 关
- `volume`：音量等级 `0-10`

### 7.2 环境采样设置
- 温湿度采样频率
- 光照采样频率
- 或统一环境采样周期

### 7.3 语音播报设置
- 环境提示开关
- 休息提醒开关
- 语音重复次数

展示方式：
- 左侧名称
- 右侧当前值
- 当前选中项高亮
- 进入编辑态后允许调整当前值

## 8. 闹钟页

采用浅层结构，避免过多跳转。

### 8.1 闹钟列表态
- 展示闹钟列表
- 每项包含：时间、星期、重复 / 单次、启用状态
- 提供新增入口
- 选中已有闹钟后先进入动作态

### 8.2 闹钟动作态
- 针对当前闹钟展示 3 个动作：`编辑 / 启用或停用 / 删除`
- 删除动作进入删除确认态，避免误触

### 8.3 闹钟编辑态
字段：
- 时
- 分
- 秒
- 星期方案
- 重复开关
- 启用开关

### 8.4 删除确认态
- 展示当前闹钟摘要
- `K1` 取消
- `K4` 确认删除

## 9. 网络页

分为三块：

### 9.1 WiFi 状态
- 当前是否连接
- 当前 SSID
- IP 地址
- 信号强度

### 9.2 网络操作
- 手动重连固定热点
- 断开当前网络

### 9.3 同步状态
- 网络时间同步状态
- Todo 云同步状态
- 最近同步时间
- 同步失败原因

如果后续需要密码输入，HTML 原型阶段只保留状态面板与动作入口，不做完整输入法。

网络页交互补充：
- 网络页先在 4 个大模块之间切换：`WiFi状态`、`动作`、`固定热点`、`同步状态`
- 模块顺序固定为：左上 -> 左下 -> 右上 -> 右下 -> 回左上
- 进入 `固定热点` 模块后，选中热点并按 `K3`，默认执行连接
- `动作` 模块显式提供“立即重连”

## 10. 关机确认页与关机态

### 10.1 关机确认页
- 中部大字：确认关机
- 辅助说明：再次确认后关闭系统
- `K1` 返回首页
- `K4` 确认关机

### 10.2 关机态
- 显示系统已关机
- 允许后续通过开机动作或任意唤醒逻辑回到首页

## 11. 交互模型

### 11.1 顶层状态
1. 正常显示态
2. 极简显示态
3. 关机态

### 11.2 人体检测规则
- 正常显示态只有在连续无人 `30s` 且连续无操作 `30s` 时才进入极简模式
- 极简模式检测到人后立即回首页
- 可在回首页时触发一次欢迎语音
- 采用连续无人计时，避免雷达抖动导致误切换
- 按键、点击、触摸不作为人感输入信号，但会刷新无操作计时

### 11.3 首页按键
- `K1`：进入设置页
- `K2`：进入闹钟页
- `K3`：进入网络页
- `K4`：进入关机确认页

### 11.4 操作页浏览态
- `K1`：上移 / 上一个
- `K2`：下移 / 下一个
- `K3`：确认 / 编辑 / 进入
- `K4`：返回首页

### 11.5 操作页编辑态
- `K1`：减小 / 左移
- `K2`：增大 / 右移
- `K3`：确认当前字段
- `K4`：取消并返回上一层

网络页例外：
- 网络页在模块选择态下，`K3` 文案固定为“选择”
- 网络页在模块内选择态下，`K3` 文案仍固定为“选择”

### 11.6 极简模式交互
- 人体检测恢复时自动回首页
- 不在极简模式下直接进入设置 / 闹钟 / 网络

## 12. 接口边界

UI 层依赖两类接口：状态读取与动作命令。

### 12.1 状态读取接口
- `clock`
  - 当前时间戳
  - 日期
  - 星期
  - 是否已校时
- `system`
  - `soundMuted`
  - `audioEnabled`
  - `powerState`
  - `currentViewMode`
- `environment`
  - `temperature`
  - `humidity`
  - `lux`
  - `lastUpdatedAt`
  - `samplingHealthy`
- `presence`
  - `detected`
  - `absenceDurationMs`
  - `thresholdMs`
  - `radarHealthy`
- `voice`
  - `currentPromptText`
  - `lastPromptType`
  - `speaking`
- `alarm`
  - `nearestAlarm`
  - `alarmList`
- `todo`
  - `todoList`
  - `syncStatus`
  - `lastSyncAt`
- `network`
  - `wifiConnected`
  - `ssid`
  - `ip`
  - `rssi`
  - `scanResults`
  - `ntpSyncStatus`
  - `todoSyncStatus`

### 12.2 动作接口
- 导航动作
  - `openSettings()`
  - `openAlarms()`
  - `openNetwork()`
  - `openPowerConfirm()`
  - `backHome()`
- 设置动作
  - `setSoundMuted(boolean)`
  - `setAudioEnabled(boolean)`
  - `setVolume(level)`
  - `setEnvSampleInterval(ms)`
  - `setVoiceRepeatCount(n)`
  - `setVoiceFeatureEnabled(type, boolean)`
- 闹钟动作
  - `createAlarm(payload)`
  - `updateAlarm(id, payload)`
  - `deleteAlarm(id)`
  - `toggleAlarm(id, enabled)`
- 网络动作
  - `scanWifi()`
  - `connectWifi(ssid, password)`
  - `disconnectWifi()`
  - `syncTime()`
  - `syncTodo()`
- 电源动作
  - `requestShutdown()`
  - `cancelShutdown()`
  - `powerOn()`

## 13. 数据流

推荐使用单向流：

1. 传感器、RTC、雷达、网络模块更新底层状态
2. 状态聚合层整理出页面所需数据
3. UI 通过定时或事件刷新
4. 按键只发命令，不直接改页面
5. 执行结果通过新状态回写到界面

刷新节奏建议：
- 时间：`1s`
- 环境参数：按配置周期刷新
- 人体检测：低延迟事件更新
- 网络与同步状态：事件驱动为主，必要时轮询

## 14. 空数据与异常规则

- 时间未同步：日期旁显示 `UNSYNC`
- 传感器异常：对应字段显示 `--`
- 无待办：显示 `No tasks`
- 无闹钟：显示 `No alarm`
- WiFi 未连接：网络页显示 `未连接`
- 云同步失败：网络页显示失败原因，首页可轻量提示
- 语音关闭：文本提示仍可显示，但不强制播报
- 雷达异常：停止自动切换极简模式，保守维持正常显示态

## 15. 验收标准

本轮交付至少满足：
- 所有目标页面均存在
- 页面间可按约定路径切换
- 首页时间层级最突出
- 极简页只保留时间
- 时间可实时刷新
- 连续无人 `30s` 后可进入极简模式
- 检测到人后可回首页
- 页面字段、动作接口、按键语义、异常规则都有明确说明
- 页面结构可迁移到 `LVGL`
