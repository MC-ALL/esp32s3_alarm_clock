# Web 用户文案与报告呈现优化设计

## 1. 目标

本设计用于收敛当前 `web/` 控制中心的用户可见文案与报告呈现风格。

本轮不改变任何业务能力边界，不新增功能，不修改 AI 数据链路，仅面向真实用户优化：

- 去掉页面中的技术实现描述
- 将全站说明文案收敛到轻提示风格
- 调整 `/model` 页输入区、空状态、按钮和报告区标题文案
- 调整环境分析报告在 Web 页面与 PDF 中的标题、时间、风险等级呈现

整体风格方向为：`轻松亲和`。

- `web/templates/todos.html`

### 2.2 不在本轮范围

- 不改 `/api/model/*` 接口结构
- 不改 AI prompt 与 schema

- 不重做全站布局
- 不新增页面
- 不新增复杂交互

## 3. 文案策略

### 3.1 总原则

- 只保留用户真正需要的轻提示
- 删除“后端、接口、同步、真源、隐藏概括、设备拉取”等技术视角表述
- 空状态保留引导，但不解释内部实现
- 错误提示继续保持简短直接

### 3.2 信息密度

采用 `轻提示` 策略：

- 页面标题保留
- 页面副标题保留简短用户提示
- 空状态保留一句自然引导
- 不出现面向开发者的实现说明

## 4. 全站文案调整

### 4.1 顶部全站说明

将当前偏技术的全站副标题替换为用户视角文案，例如：

- `在这里查看状态、整理待办和管理提醒。`

### 4.2 设备状态页

- 副标题从“最近一次状态上报快照”改为用户可理解的说明
- `是否有人` 改为 `在位状态`

### 4.3 待办页

- 删除“设备端只拉取这里的内容”
- 已完成区不再强调“Web 端 / 设备端”差异
- 空状态改成自然引导

### 4.4 闹钟页

- 删除“Web 真源”“配置快照拉取”等术语
- 保留用户操作语义：新增、删除、保存

### 4.5 语音页

- 删除“与设备端字段保持一致”这类实现说明
- 改为用户可理解的功能说明

### 4.6 事件页

- 删除“事件只存 Web 后端，设备不保留历史”
- 改为用户视角说明，例如“查看最近发生的提醒和操作”
- 空状态改成温和短句

## 5. `/model` 页文案与结构微调

### 5.1 页面定位文案

- 页面标题改为 `模型对话`
- 页面副标题改成用户视角说明，例如：
  - `可以问环境状态、提醒节奏和日常建议。`

### 5.2 对话区

- 删除“只读助手”“隐藏概括”这类实现词
- 输入框占位改为：`请输入疑问`
- “发送问题”改为更自然的用户动作文案
- 聊天气泡中用户角标 `你` 改为 `请输入疑问`
- 助手角标 `助手` 改为 `建议`
- 清空按钮改为更轻量的用户表达
- 清空确认框改成用户能直接理解的短句

### 5.3 报告区

- 报告标题统一改为：`环境分析报告`
- 删除英文 `LATEST HEALTH REPORT`
- 删除“只在点击时调用 AI”“只保留最近一份报告”等内部说明
- 报告空状态改成自然说明，例如“生成后可以在这里查看最近一份结果”

## 6. 时间与显示格式

### 6.1 Web 页面时间格式

报告生成时间只显示：

- `YYYY-MM-DD HH:MM`

不显示：

- 秒
- 时区
- `T`
- `+08:00`
- 多余的标签前缀，如 `生成时间：`

### 6.2 PDF 时间格式

PDF 中生成时间与 Web 保持一致，统一使用：

- `YYYY-MM-DD HH:MM`

## 7. 报告卡片呈现

### 7.1 Web 侧

保留当前卡片结构，但优化：

- 主标题为 `环境分析报告`
- 风险等级单独显示
- 生成时间单独显示
- 不再使用英文眉题
- 让顶部信息区更像用户报告，而不是调试卡片

### 7.2 PDF 侧

PDF 不修改内容结构，只调整呈现：

- 标题固定为 `环境分析报告`
- PDF title 不拼接时间戳
- 生成时间单独一行或单独一块
- 风险等级单独换行
- 段落留白更舒展
- 整体更贴近 Web 侧当前面板风格

## 8. 最小变更边界

本轮仅做：

- 文案替换
- 时间格式调整
- 报告标题与元信息显示调整
- PDF 元信息排版调整
- 少量 CSS 微调

不做：

- 接口改动
- 报告字段改动
- 页面重排
- 全站主题重做

## 9. 验收标准

- 页面中不再出现明显技术实现描述
- `/model` 输入框占位为 `请输入疑问`
- `/model` 聊天气泡用户角标不再显示 `你`
- 报告标题统一为 `环境分析报告`
- Web 报告区不再显示英文 title
- Web 报告生成时间只显示 `YYYY-MM-DD HH:MM`
- PDF 标题不带时间戳
- PDF 中风险等级单独换行
- 全站文案整体更像面向用户的产品页面
