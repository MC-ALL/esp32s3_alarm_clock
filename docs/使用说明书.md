# 智能闹钟使用说明书

## 1. 文档目的
本文档用于说明当前固件版本下，各页面的：
- 页面作用
- 页面跳转逻辑
- `K1` ~ `K4` 按键功能
- 页面切换后按键功能如何变化

本文档以**当前代码实际实现**为准，不以早期草图或旧版设计图为准。

---

## 2. 设备按键说明
设备共有 4 个实体按键，本文统一记为：
- `K1`
- `K2`
- `K3`
- `K4`

不同页面下，4 个按键的功能会变化。
屏幕底部一行提示文字，会同步显示当前页面下 4 个按键各自对应的作用。

---

## 3. 页面总览
当前页面体系如下：

1. 首页 `HOME`
2. 极简显示状态 `MINIMAL`
3. 设置页 `SETTINGS`
4. 闹钟页 `ALARM`
5. 网络页 `NETWORK`
6. 关机确认页 `POWER`
7. 闹钟响铃页

说明：
- “闹钟响铃页”在实现上复用了 `POWER` 页面容器，但显示内容和按键逻辑与普通关机确认不同。
- 极简显示状态不是普通子页面，而是一种特殊显示状态。

---

## 4. 首页说明

### 4.1 首页显示内容
首页主要显示：
- 日期
- 当前时间
- 声音状态 `SND ON/OFF`
- 语音状态 `AUD ON/OFF`
- 环境数据：温度、湿度、光照
- 环境提示文本
- 最近闹钟摘要
- Todo List 摘要
- 底部页面跳转按键提示

### 4.2 首页按键功能
首页下，按键功能固定为：

| 按键 | 功能 |
| --- | --- |
| `K1` | 进入设置页 |
| `K2` | 进入闹钟页 |
| `K3` | 进入网络页 |
| `K4` | 进入关机确认页 |

### 4.3 首页跳转逻辑
- `K1`：`HOME -> SETTINGS`
- `K2`：`HOME -> ALARM`
- `K3`：`HOME -> NETWORK`
- `K4`：`HOME -> POWER`

---

## 5. 极简显示状态说明

### 5.1 进入条件
当前实现中，当同时满足以下条件时，系统会自动进入极简显示状态：
- 持续无人检测一段时间
- 持续无按键操作一段时间
- 雷达状态正常

### 5.2 极简显示内容
极简状态下，屏幕仅保留最简时间显示，不显示底部按键提示栏。

### 5.3 退出条件
当重新检测到人，并且雷达状态正常时，系统会退出极简状态，恢复正常首页显示。

### 5.4 欢迎提示音逻辑
极简状态恢复到正常显示时：
- 如果本轮极简状态还没有播过欢迎音，则会播一次欢迎提示音
- 如果已经播过，则同一轮不会重复播
- 重新进入极简状态后，欢迎逻辑才会重新武装

说明：
- 极简状态不提供独立按键交互说明
- 用户实际恢复后会直接回到首页逻辑

---

## 6. 设置页说明

### 6.1 进入方式
从首页按 `K1` 进入设置页。

### 6.2 设置项
当前实现中的设置项包括：
1. `SOUND`
2. `AUDIO`
3. `VOLUME`
4. `ENV SAMPLE`
5. `REPEAT`

其中：
- `SOUND`：声音开关
- `AUDIO`：语音开关
- `VOLUME`：音量大小
- `ENV SAMPLE`：环境采样参数占位
- `REPEAT`：单次闹钟触发后，提示音最多重复播放次数

### 6.3 设置页有两种状态
设置页有两种交互状态：
1. 浏览状态 `BROWSE`
2. 修改状态 `EDIT`

页面底部按键提示会根据状态变化。

---

### 6.4 设置页浏览状态
浏览状态下，按键功能如下：

| 按键 | 功能 |
| --- | --- |
| `K1` | 光标上移 |
| `K2` | 光标下移 |
| `K3` | 修改 / 进入编辑 |
| `K4` | 返回首页 |

#### 6.4.1 浏览状态下的具体行为
- 当焦点在 `SOUND` 上时，按 `K3`：直接切换 `ON/OFF`
- 当焦点在 `AUDIO` 上时，按 `K3`：直接切换 `ON/OFF`
- 当焦点在 `VOLUME / ENV SAMPLE / REPEAT` 上时，按 `K3`：进入修改状态

#### 6.4.2 页面跳转逻辑
- `K4`：`SETTINGS -> HOME`

---

### 6.5 设置页修改状态
修改状态只用于：
- `VOLUME`
- `ENV SAMPLE`
- `REPEAT`

修改状态下，按键功能如下：

| 按键 | 功能 |
| --- | --- |
| `K1` | 增加数值 |
| `K2` | 减少数值 |
| `K3` | 保存修改 |
| `K4` | 取消并返回浏览状态 |

#### 6.5.1 状态变化逻辑
- 浏览状态按 `K3` 进入修改状态
- 修改完成后按 `K3` 保存，返回浏览状态
- 修改过程中按 `K4` 放弃当前修改，返回浏览状态

#### 6.5.2 说明
当前实现中：
- `VOLUME` 会实际影响音量大小
- `REPEAT` 会影响闹钟提示音的重复播放次数
- `ENV SAMPLE` 目前主要是本地参数显示，未形成完整环境任务重配置链路

---

## 7. 闹钟页说明

### 7.1 进入方式
从首页按 `K2` 进入闹钟页。

### 7.2 闹钟页包含 4 种状态
当前实现中，闹钟页有 4 个交互状态：
1. 列表态 `LIST`
2. 动作态 `ACTION`
3. 编辑态 `EDIT`
4. 删除确认态 `DELETE_CONFIRM`

页面底部按键提示会跟随状态切换。

---

### 7.3 列表态 `LIST`
列表态用于：
- 浏览已有闹钟
- 选择新建闹钟
- 进入某个闹钟的动作菜单

列表态下，按键功能如下：

| 按键 | 功能 |
| --- | --- |
| `K1` | 上移 |
| `K2` | 下移 |
| `K3` | 选择 |
| `K4` | 返回首页 |

#### 7.3.1 列表态行为
列表中包含：
- `+ NEW ALARM`
- 已有闹钟列表

按 `K3` 时：
- 如果当前焦点在 `+ NEW ALARM`，则进入编辑态，新建闹钟
- 如果当前焦点在已有闹钟，则进入动作态

#### 7.3.2 页面跳转逻辑
- `K4`：`ALARM(LIST) -> HOME`
- `K3` 选中 `+ NEW ALARM`：`ALARM(LIST) -> ALARM(EDIT)`
- `K3` 选中已有闹钟：`ALARM(LIST) -> ALARM(ACTION)`

---

### 7.4 动作态 `ACTION`
动作态用于对某个已存在闹钟执行操作。

当前动作包括：
1. `EDIT`
2. `TOGGLE`
3. `DELETE`
4. `BACK`

动作态下，按键功能如下：

| 按键 | 功能 |
| --- | --- |
| `K1` | 上移 |
| `K2` | 下移 |
| `K3` | 执行当前动作 |
| `K4` | 返回列表态 |

#### 7.4.1 动作态行为
- `EDIT`：进入编辑态，修改当前闹钟
- `TOGGLE`：启用 / 停用当前闹钟
- `DELETE`：进入删除确认态
- `BACK`：回到列表态

#### 7.4.2 页面跳转逻辑
- `K4`：`ALARM(ACTION) -> ALARM(LIST)`
- `K3` 选中 `EDIT`：`ALARM(ACTION) -> ALARM(EDIT)`
- `K3` 选中 `DELETE`：`ALARM(ACTION) -> ALARM(DELETE_CONFIRM)`
- `K3` 选中 `BACK`：`ALARM(ACTION) -> ALARM(LIST)`
- `K3` 选中 `TOGGLE`：切换启用状态后回到 `ALARM(LIST)`

---

### 7.5 编辑态 `EDIT`
编辑态用于：
- 新建闹钟
- 修改现有闹钟

可编辑字段为：
1. `HOUR`
2. `MINUTE`
3. `SECOND`
4. `REPEAT`
5. `ENABLED`

编辑态下，按键功能如下：

| 按键 | 功能 |
| --- | --- |
| `K1` | 减小 / 切换当前字段 |
| `K2` | 增大 / 切换当前字段 |
| `K3` | 下一字段 / 保存 |
| `K4` | 取消 |

#### 7.5.1 编辑态行为
- 当焦点在 `HOUR / MINUTE / SECOND` 上时：
  - `K1` 为减小
  - `K2` 为增大
- 当焦点在 `REPEAT / ENABLED` 上时：
  - `K1` 和 `K2` 都是切换布尔值
- `K3`：
  - 如果还没到最后一个字段，则进入下一个字段
  - 如果已经在最后一个字段，则保存并返回列表态
- `K4`：取消编辑

#### 7.5.2 页面跳转逻辑
- 新建闹钟时按 `K4`：`ALARM(EDIT) -> ALARM(LIST)`
- 编辑已有闹钟时按 `K4`：`ALARM(EDIT) -> ALARM(ACTION)`
- 编辑完成按 `K3` 保存：`ALARM(EDIT) -> ALARM(LIST)`

---

### 7.6 删除确认态 `DELETE_CONFIRM`
删除确认态用于确认是否删除当前闹钟。

删除确认态下，按键功能如下：

| 按键 | 功能 |
| --- | --- |
| `K1` | 取消 |
| `K2` | 无功能 |
| `K3` | 无功能 |
| `K4` | 删除 |

#### 7.6.1 页面跳转逻辑
- `K1`：`ALARM(DELETE_CONFIRM) -> ALARM(ACTION)`
- `K4`：删除后 `ALARM(DELETE_CONFIRM) -> ALARM(LIST)`

---

## 8. 网络页说明

### 8.1 进入方式
从首页按 `K3` 进入网络页。

### 8.2 网络页模块
网络页当前有 4 个模块：
1. `WIFI STATUS`
2. `ACTION`
3. `MY NET`
4. `SYNC STATUS`

### 8.3 网络页有两种状态
1. 模块浏览状态
2. 动作选择状态

注意：
- 当前只有 `ACTION` 模块可以进入动作选择状态
- 其他模块仅供查看，不提供页内编辑

---

### 8.4 模块浏览状态
模块浏览状态下，按键功能如下：

| 按键 | 功能 |
| --- | --- |
| `K1` | 切到上一个模块 |
| `K2` | 切到下一个模块 |
| `K3` | 选择 |
| `K4` | 返回首页 |

#### 8.4.1 浏览状态行为
- 当焦点在 `ACTION` 模块时，按 `K3`：进入动作选择状态
- 当焦点在 `WIFI STATUS / MY NET / SYNC STATUS` 时，按 `K3`：只刷新当前内容，不进入新的子逻辑

#### 8.4.2 页面跳转逻辑
- `K4`：`NETWORK -> HOME`
- `K3` 在 `ACTION` 上：`NETWORK(MODULE) -> NETWORK(ACTION)`

---

### 8.5 动作选择状态
动作选择状态下，当前可选项为：
1. `CONNECT NOW`
2. `SYNC TODO`
3. `BACK`

动作选择状态下，按键功能如下：

| 按键 | 功能 |
| --- | --- |
| `K1` | 上移 |
| `K2` | 下移 |
| `K3` | 执行动作 |
| `K4` | 返回模块浏览状态 |

#### 8.5.1 动作说明
- `CONNECT NOW`：立即手动触发一次固定热点连接尝试
- `SYNC TODO`：立即手动访问 Web，拉取一次 Todo List
- `BACK`：退出动作选择状态

#### 8.5.2 页面跳转逻辑
- `K4`：`NETWORK(ACTION) -> NETWORK(MODULE)`
- `K3` 选中 `BACK`：`NETWORK(ACTION) -> NETWORK(MODULE)`
- `K3` 选中 `CONNECT NOW`：执行后回到 `NETWORK(MODULE)`
- `K3` 选中 `SYNC TODO`：执行后回到 `NETWORK(MODULE)`

---

### 8.6 各模块用途说明

#### 8.6.1 `WIFI STATUS`
显示：
- 当前 SSID
- Wi-Fi 是否已启动
- 是否已连接
- IP 是否就绪

#### 8.6.2 `ACTION`
用于执行网络相关动作。
当前只提供：
- 立即重连
- 立即同步 Todo
- 返回

#### 8.6.3 `MY NET`
仅用于查看当前固定目标热点的连接情况。
显示逻辑为：
- 如果当前已连接目标热点，则显示 `CONNECTED`
- 否则显示 `NOT CONNECTED`

说明：
- 该页面当前不是扫描列表页面
- 不提供热点选择功能
- 不提供连接切换功能

#### 8.6.4 `SYNC STATUS`
显示：
- 时间同步状态
- Wi-Fi 在线状态
- 当前 IP
- Todo 同步状态
- 最近一次 Todo 同步时间

---

## 9. 关机确认页说明

### 9.1 进入方式
从首页按 `K4` 进入关机确认页。

### 9.2 当前实现说明

也就是说：

### 9.3 按键功能
关机确认页下，按键功能如下：

| 按键 | 功能 |
| --- | --- |
| `K1` | 返回首页 |
| `K2` | 无功能 |
| `K3` | 无功能 |
| `K4` | 确认 |

### 9.4 页面跳转逻辑
- `K1`：`POWER -> HOME`
- `K4`：显示确认文本，但当前不会真正执行硬件关机

## 10. 闹钟响铃页说明

### 10.1 进入方式
当某条已启用闹钟命中当前时间时，系统会自动进入闹钟响铃页。

### 10.2 显示内容
当前实现中，闹钟响铃页会：
- 黑底显示闹钟时间
- 中央显示当前响铃闹钟的 `HH:MM:SS`
- 下方显示 `PRESS ANY KEY TO STOP`

### 10.3 提示音逻辑
- 响铃时会播放闹钟提示音
- 单次触发最多播放 `REPEAT` 次
- `REPEAT` 来自设置页参数
- 如果 `REPEAT = 0`，当前实现会按 `1` 次处理

### 10.4 按键功能
响铃状态下，4 个按键功能一致：

| 按键 | 功能 |
| --- | --- |
| `K1` | 停止 |
| `K2` | 停止 |
| `K3` | 停止 |
| `K4` | 停止 |

### 10.5 页面跳转逻辑
- 任意按键：停止当前闹钟提醒，返回首页

---

## 11. 页面跳转总表

### 11.1 主页面跳转
- `HOME -> SETTINGS`：首页按 `K1`
- `HOME -> ALARM`：首页按 `K2`
- `HOME -> NETWORK`：首页按 `K3`
- `HOME -> POWER`：首页按 `K4`

### 11.2 设置页返回
- `SETTINGS -> HOME`：浏览状态按 `K4`
- `SETTINGS(EDIT) -> SETTINGS(BROWSE)`：编辑状态按 `K3` 保存或按 `K4` 取消

### 11.3 闹钟页内部跳转
- `ALARM(LIST) -> HOME`：按 `K4`
- `ALARM(LIST) -> ALARM(EDIT)`：选中 `+ NEW ALARM` 后按 `K3`
- `ALARM(LIST) -> ALARM(ACTION)`：选中已有闹钟后按 `K3`
- `ALARM(ACTION) -> ALARM(LIST)`：按 `K4` 或动作完成返回
- `ALARM(ACTION) -> ALARM(EDIT)`：选中 `EDIT` 后按 `K3`
- `ALARM(ACTION) -> ALARM(DELETE_CONFIRM)`：选中 `DELETE` 后按 `K3`
- `ALARM(DELETE_CONFIRM) -> ALARM(ACTION)`：按 `K1`
- `ALARM(DELETE_CONFIRM) -> ALARM(LIST)`：按 `K4`

### 11.4 网络页内部跳转
- `NETWORK -> HOME`：浏览状态按 `K4`
- `NETWORK(MODULE) -> NETWORK(ACTION)`：在 `ACTION` 模块按 `K3`
- `NETWORK(ACTION) -> NETWORK(MODULE)`：按 `K4` 或选 `BACK`

### 11.5 关机确认页
- `POWER -> HOME`：按 `K1`

### 11.6 响铃页
- `ALARM RINGING -> HOME`：任意按键停止

---

## 12. 当前实现限制说明
为避免误解，当前版本还存在以下限制：

1. 关机确认页尚未接真实硬件关机动作
2. 网络页不支持手动切换任意热点，只支持固定热点模式
3. `MY NET` 页面只做连接状态查看，不做热点扫描列表选择
4. `ENV SAMPLE` 目前未形成完整动态重配置链路
5. 闹钟数据目前主要是本地运行态模型，长期持久化能力仍需继续完善
6. Todo List 需要依赖局域网 Web 服务，闹钟端本身不负责编辑 Todo 文本

---

## 13. 使用建议
1. 日常查看时间、环境、Todo，请停留在首页
2. 需要改声音、音量、闹钟重复播放次数，请进入设置页
3. 需要管理闹钟，请进入闹钟页
4. 需要检查联网状态或手动同步 Todo，请进入网络页
5. 长时间无人且无操作时，系统会自动进入极简显示状态
6. 若闹钟响起，按任意一个按键即可停止当前提醒
