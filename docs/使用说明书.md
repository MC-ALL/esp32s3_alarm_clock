# 智能闹钟使用说明书

## 1. 文档目的

本文档用于说明当前固件版本下：

- 主页面组成
- 页面切换方式
- 4 个按键在不同页面中的作用
- 当前可直接使用的核心功能

本文档以当前代码实际实现为准。

---

## 2. 设备按键说明

设备共有 4 个实体按键。

当前代码中，底栏用 4 个图标表示它们的作用，大致语义如下：

- 第 1 键：返回首页或在列表页中向下移动焦点
- 第 2 键：切换到前一个主页面，或在设置视图中上移
- 第 3 键：切换到后一个主页面，或在设置视图中下移
- 第 4 键：进入设置 / 执行当前操作

由于页面状态不同，同一个按键在不同页面下的作用会发生变化。

---

## 3. 当前页面总览

当前系统主页面包括：

1. `HOME`
2. `ALARM`
3. `TODO`
4. `ENV`
5. `WIFI`
6. `LOW_CLOCK`

此外，还有对应的设置页或编辑页：

- `HOME_SETTINGS`
- `ALARM_SETTINGS`
- `ALARM_ITEM`
- `TODO_SETTINGS`
- `TODO_ITEM`
- `TODO_DELETE_CONFIRM`
- `ENV_SETTINGS`
- `LOW_SETTINGS`

---

## 4. 首页 `HOME`

### 4.1 页面作用

首页用于集中显示时间、日期、最近闹钟和 Todo 数量。

### 4.2 显示内容

当前首页会显示：

- 当前时间
- 日期
- 最近一个已启用闹钟
- 当前未完成 Todo 数量

当启用纯时钟布局时，首页只显示时间和日期。

### 4.3 按键功能

在首页下：

- 第 1 键：若不在首页则返回首页
- 第 2 键：切换到上一个主页面
- 第 3 键：切换到下一个主页面
- 第 4 键：进入 `HOME_SETTINGS`

### 4.4 可修改内容

进入 `HOME_SETTINGS` 后，可修改：

- 首页布局模式
- 12/24 小时制
- 整点提示开关

---

## 5. 闹钟页 `ALARM`

### 5.1 页面作用

闹钟页用于浏览和管理当前本地闹钟。

### 5.2 主页面显示

当前会显示：

- 所有闹钟时间
- 每条闹钟的启用状态

### 5.3 主页面按键

在 `ALARM` 页面下：

- 第 1 键：列表焦点下移
- 第 2 键：切换到前一个主页面
- 第 3 键：切换到后一个主页面
- 第 4 键：进入 `ALARM_SETTINGS`

### 5.4 设置页 `ALARM_SETTINGS`

当前可操作内容包括：

- 闹钟语音总开关
- 闹钟语音测试
- 新增闹钟
- 删除最后一个闹钟
- 进入某条闹钟的详细编辑页

### 5.5 单条闹钟编辑页 `ALARM_ITEM`

进入后可以修改：

- 时间
- 是否重复
- 是否启用语音
- 是否启用该闹钟

修改后会立即保存到本地设置中。

---

## 6. Todo 页 `TODO`

### 6.1 页面作用

Todo 页用于查看从 Web 同步到本地的待办事项。

### 6.2 主页面显示

当前页面会显示：

- Todo 列表
- 每条 Todo 的完成状态
- 一个 `SETTINGS` 入口

### 6.3 主页面按键

在 `TODO` 页面下：

- 第 1 键：列表焦点下移
- 第 2 键：切换到前一个主页面
- 第 3 键：切换到后一个主页面
- 第 4 键：
  - 若焦点在 Todo 项上，则进入 `TODO_ITEM`
  - 若焦点在 `SETTINGS` 上，则进入 `TODO_SETTINGS`

### 6.4 设置页 `TODO_SETTINGS`

当前可用项包括：

- 立即同步 Todo
- 切换自动同步周期
- Todo 提示语音开关
- Todo 语音测试（播放 Todo 同步提示音）

### 6.5 单条 Todo 操作页 `TODO_ITEM`

当前支持：

- 标记完成 / 取消完成
- 删除 Todo

这些操作会立即同步请求到 Web 端；删除时会进入 `TODO_DELETE_CONFIRM` 进行确认。

---

## 7. 环境页 `ENV`

### 7.1 页面作用

环境页用于集中查看环境和存在检测状态。

### 7.2 显示内容

当前页面分为 4 个信息块：

- 温度 `TEMP`
- 湿度 `HUMI`
- 光照 `LUX`
- 雷达状态 `RADAR`

当环境值超出阈值时，对应区域会显示为告警颜色。

### 7.3 主页面按键

在 `ENV` 页面下：

- 第 2 键：切换到前一个主页面
- 第 3 键：切换到后一个主页面
- 第 4 键：进入 `ENV_SETTINGS`

### 7.4 设置页 `ENV_SETTINGS`

当前可调整内容包括：

- 环境语音开关
- 环境语音测试
- 采样周期
- 温度上下限
- 湿度上下限
- 光照上下限
- 环境提醒开关

---

## 8. 网络页 `WIFI`

### 8.1 页面作用

网络页用于查看联网、校时和 Todo 同步结果。

### 8.2 显示内容

页面当前显示 4 个状态块：

- `WIFI`
- `IP`
- `TIME`
- `TODO`

其中：

- `WIFI` 显示是否联网
- `IP` 显示当前 IP
- `TIME` 显示校时状态
- `TODO` 显示 Todo 同步状态

### 8.3 当前交互

在 `WIFI` 页面下：

- 第 2 键：切换到前一个主页面
- 第 3 键：切换到后一个主页面
- 第 4 键：当前没有独立设置视图

说明：

- 当前代码中不再使用旧的 `WIFI STATUS / ACTION / MY NET / SYNC STATUS` 页面结构
- 手动同步和 Todo 操作已经转入 `TODO_SETTINGS` 与 Todo 页面相关流程中

---

## 9. 低干扰时钟页 `LOW_CLOCK`

### 9.1 页面作用

当长时间无人时，系统会自动切换到低干扰时钟页。

### 9.2 进入条件

当持续无人达到设定时间后，系统会从当前主页面切换到 `LOW_CLOCK`。

### 9.3 退出条件

重新检测到人在位，并持续达到设定退出时间后，系统会返回首页。

### 9.4 显示内容

当前页面仅显示：

- 时间
- 日期

### 9.5 设置页 `LOW_SETTINGS`

进入后可调整：

- 12/24 小时制
- 进入低干扰页所需无人时长
- 从低干扰页退出所需在位时长

---

## 10. 当前可直接使用的功能

结合当前代码，设备已经可以完成以下操作：

1. 查看当前时间和日期
2. 浏览本地闹钟列表
3. 新增、修改和删除闹钟
4. 查看 Todo 列表
5. 手动同步 Todo
6. 标记 Todo 完成或删除 Todo
7. 查看环境信息和雷达存在状态
8. 调整环境提醒参数
9. 查看 Wi-Fi、IP、校时和 Todo 同步状态
10. 在长时间无人时自动进入低干扰时钟页

---

## 11. 当前实现限制

为避免误解，当前仍有以下限制：

1. 当前没有独立的普通关机确认页交互主线。
2. 当前 UI 不再是早期文档中的 `SETTINGS / NETWORK / POWER` 页面体系。
3. Todo 同步目标地址仍依赖本地配置。
4. `DHT11` 仍然存在一定稳定性问题。
5. Todo 数据解析当前仍采用轻量字符串解析方式。

因此，当前系统适合定位为：

- 功能主链已跑通的课程项目原型

而不是：

- 已完全收敛的产品化系统
